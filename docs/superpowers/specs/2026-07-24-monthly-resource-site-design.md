# 月度资源整合网站实现规格

## 目标

把用户提供的七月 v1.3 资源清单实现为可直接托管到 Cloudflare Pages 的响应式静态网站，并保持 Figma 中的
米白、墨黑、朱红视觉方向。完整内容属于网站数据层，不复制到 Figma。

## 页面

- `/`：月刊首页，展示当前月份、版本、发布日期、作者、资源总数及历史月份入口。
- `/2026/07/`：七月月刊详情，展示完整资源列表和版本、搜索、分类、复制链接交互。

## 数据

- 七月 v1.3 收录用户提供的 81 条资源。
- 每条记录包含名称、简介、分类、来源域名、原始地址、最终地址、来源类型、可访问状态、核对日期和视觉素材。
- 当前只发布有真实内容的 v1.3，不伪造 v1.1、v1.2 快照；数据结构允许后续追加完整版本。
- 可用素材优先使用已采集截图、封面或图标；没有稳定素材时使用分类占位视觉。

## 交互

- 搜索匹配名称、简介和来源域名。
- 分类为单选；可一键清除搜索和分类。
- 版本选择器默认使用最新版。
- 地址栏同步 `v`、`category`、`q`，可复制当前筛选状态的分享链接。
- 可用资源提供“打开链接”和“复制链接”；暂不可用资源只保留复制原始地址。
- 复制成功使用可被辅助技术读取的短暂提示。

## 视觉与响应式

- 使用 Figma 设计令牌：纸张色 `#F7F1E5`、表面色 `#FFFCF7`、墨黑 `#181715`、朱红 `#B82C22`。
- 中文标题优先使用 `Noto Serif SC`，正文使用 `Noto Sans SC`，并提供系统字体回退。
- 桌面端详情使用双列资源卡；手机端使用单列资源卡。
- 所有主要触控控件高度不低于 48px。
- 资源图片保持比例，不拉伸；缺图时显示稳定的分类占位视觉。

## 无障碍与错误处理

- 使用语义化标题、导航、表单、列表和状态区域。
- 正文与背景对比度不低于 4.5:1，键盘焦点清晰可见。
- 外部链接使用安全的 `rel` 属性。
- 无搜索结果、链接不可用和剪贴板失败均有明确反馈。

## 非目标

- 不实现登录、收藏、评论、投稿、管理后台、深色模式或自动巡检。
- 不在本轮部署到第三方托管；完成后提交并推送到用户指定的 GitHub 仓库。

## 验收

- 根页面和七月详情页可通过直接 URL 访问。
- 81 条资源均能在 v1.3 数据中找到且字段完整。
- 搜索、分类、版本、分享参数、复制和不可用状态行为通过自动测试。
- 桌面和 390px 手机视口无横向溢出、文字遮挡和图片拉伸。
- `npm test` 与 `npm run build` 均成功。
